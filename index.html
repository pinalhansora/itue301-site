Course Outcomes

By the end of the course, students will be able to:

CO1

Design and implement component-based frontend systems using reactive state management and performance optimization strategies for scalable web applications.

CO2

Design and implement secure RESTful backend services incorporating middleware pipelines, validation layers, and caching mechanisms.

CO3

Select and evaluate appropriate data modeling, migration, encryption, and storage strategies based on workload characteristics and consistency requirements.

CO4

Design scalable web system architectures by applying stateless service design, load balancing, asynchronous processing, and performance profiling techniques.

CO5

Implement cloud-native deployment pipelines using containerization, CI/CD automation, and deployment strategies while monitoring reliability and resource optimization.

CO6

Apply security engineering principles and responsibly integrate AI-based services into web systems while analyzing ethical, privacy, and governance implications.

Practicals

One project, twelve labs — the Car Details Management System, built up in React, Node/Express, and MySQL.

Wk 1–2
Lab 1–2
Environment setup, JSX & basic components · Props & component composition
Completed
Wk 3
Lab 3
State management & dynamic rendering — search, filter, view toggle
Completed
  1. Convert the static car array into a state variable using useState in App.jsx (or a parent container component).
  2. Add a search input box above the car list; filter and display only cars whose make or model matches the typed text.
  3. Add a dropdown to filter cars by fuel type (All / Petrol / Diesel / Electric).
  4. Add a toggle button to switch the car list between Grid view and List view using conditional rendering.
  5. Display the total number of cars and the number of cars matching the current filter, updated dynamically.
  6. Bonus: Use useEffect to log a message to the console every time the filtered list changes.
Wk 4
Lab 4
React Router — multi-page navigation
Upcoming
  1. Install react-router-dom and set up routing in App.jsx with routes for Home, Add Car, Car Details, and Old Car Parts pages.
  2. Create a Navbar component with links to Home, Add Car, and Old Car Parts pages using the Link component.
  3. Implement a dynamic route /car/:id that displays a Car Details page for the selected car (use useParams).
  4. On the car list, wrap each CarCard in a Link so clicking it navigates to /car/:id.
  5. Add a simple 404 'Page Not Found' route for any unmatched URL.
  6. Bonus: Use useNavigate to add a 'Back to List' button on the Car Details page.
